CSS Custom properties

Every CSS variable the player reads, and what it defaults to.

The player uses CSS custom properties extensively. If you're self-hosting instead of using our embed or direct share link, you can set any of them on the player's container — or any ancestor of it — and the player picks them up. This is the route to more control than the Appearance settings offer. It needs no build step and no overriding of the player's own rules: 

#my-timeline {
  --tl-color-accent: #0066cc;
  --tl-font-heading: Georgia, serif;
  --tl-slide-padding: 3rem;
}

Because these are ordinary custom properties, everything CSS already does works: set them inside a media query, scope them to one timeline among several, or change them at runtime from JavaScript with element.style.setProperty().

Properties marked dark have a separate value in dark mode. Setting one of these yourself replaces it in both modes, so if you want the two to differ you need to say so — usually by setting the property again inside [data-tl-theme="dark"] and a prefers-color-scheme query.

The example-custom-theme app builds a complete visual identity out of nothing but this list, which is a good place to see how far it goes.
